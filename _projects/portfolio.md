# Portfolio Website - Professional Software Engineering Portfolio

## Project Overview

A modern, responsive portfolio website designed to showcase professional software engineering experience, technical projects, certifications, and skills. Built with clean design principles and optimized for performance and accessibility.

## Key Features

- Responsive design with mobile-first approach for all devices
- Interactive project showcase with filtering by technology stack
- Comprehensive certifications and skills display
- Professional experience timeline with detailed descriptions
- Contact section with integrated social media links
- Fast loading times with optimized assets and lazy loading
- SEO-optimized structure for better discoverability

## Technologies Used

- HTML5 for semantic markup and structure
- CSS3 for styling with Flexbox and Grid layouts
- JavaScript for interactive elements and animations
- Jekyll for static site generation and templating
- GitHub Pages for hosting and deployment
- Responsive design principles for cross-device compatibility

## Technical Highlights

- Clean, maintainable code structure following best practices
- Cross-browser compatibility testing and optimization
- Accessibility features meeting WCAG standards
- Performance optimization with minimized CSS/JS
- Version control with Git and GitHub workflow

## Usage

- Visit the live site at [crissyg.github.io/portfolio-CGordon](https://crissyg.github.io/portfolio-CGordon/)
- Browse projects by category and technology
- View detailed certifications and professional experience
- Connect via social media links and contact information
